# Računko – datoteke za prenos

V tem repozitoriju **ni kode**, samo namestitvene datoteke aplikacij Računko.

- **Android blagajna:** [racunko-pos.apk](https://github.com/mahnicnik/racunko-izdaje/releases/download/android/racunko-pos.apk)

Prenos je na voljo tudi v aplikaciji: **Računko → Nastavitve → Prenosi**.

Datoteke objavlja `apps/mobile/objavi-android.sh` oz. GitHub Action `Objavi Android APK` v (zasebnem) repozitoriju s kodo.
